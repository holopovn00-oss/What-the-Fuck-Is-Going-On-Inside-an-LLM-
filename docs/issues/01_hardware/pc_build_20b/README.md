# Локальный ИИ-ПК: сборка и 20B

Практическое продолжение к [утверждённому выпуску 1.1](../README.md). Его файл сохранён побайтно; это самостоятельная шестистраничная глава в том же книжном макете: две страницы статьи, затем местная библиография; два смысловых раздела.

- [PDF](pc_build_20b.pdf) · [редактируемый текст](pc_build_20b.md)
- [Источники и разделы](sources.json) · [редакторская проверка](EDITORIAL_REVIEW.md)
- [Исходник содержания](content.py) · [скрипт вёрстки](typeset.py)

Первая тройка страниц различает плотную 20B и MoE, инференс, QLoRA, полное обучение и службу с несколькими запросами. Вторая даёт три проверяемых класса сборки (16/24/32 GiB) с CPU, RAM, платой, дисками, питанием, охлаждением и протоколом приёмки.

Числа для весов и KV — учебные расчёты; видеокарты — примеры по референсным спецификациям производителей. Точных артикулов CPU, платы, памяти, партнёрской GPU, блока питания, цен и испытаний готовой машины здесь нет. Их нельзя честно выбрать без точной модели, версии runtime, бюджета и рынка. **Статус этой новой главы: редакторский допуск, оценка пользователя ожидается.**

Из корня репозитория: `python3 docs/issues/01_hardware/pc_build_20b/typeset.py`. Требуются зависимости и шрифты, перечисленные в [README выпуска 1.1](../README.md). Пересборка может поменять бинарный файл PDF; до правки исходника сравнивайте с опубликованным.

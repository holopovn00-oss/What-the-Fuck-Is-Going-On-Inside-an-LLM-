Это восемь частей, каждая состоит из двух страниц статьи и следующей за ними местной библиографии, всего 24 страницы A4. PDF набран по структуре утверждённого эталона Deep Research. Скрипт build_pdf.py использует hardware_content.py и typeset_reference.py; сборка требует pyphen, XeLaTeX, polyglossia, Nimbus Sans и шрифты assets/fonts. Техническая пересборка может изменить бинарный PDF, поэтому текущий восстановленный файл хранится отдельно и сверяется по SHA-256.

Калькулятор даёт нижние оценки массивов, но не гарантирует совместимость устройства. Проверка конкретных комплектующих и цен требует выбранного checkpoint, версии software и нагрузки.

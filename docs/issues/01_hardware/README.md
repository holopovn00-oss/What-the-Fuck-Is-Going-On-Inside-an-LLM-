# Выпуск 01. Железо для ИИ: от задачи к конфигурации

Готовая обзорная редакция по блоку VII Атласа. Восемь частей, 24 страницы, 32 местные библиографические записи (27 разных источников). Композиция соответствует утверждённой главе Deep Research.

- [Читать PDF](hardware_issue.pdf)
- [Читать/редактировать Markdown](hardware_issue.md)
- [Журнал проверки и карта тем 7.1–7.12](review_log.md)
- [Структурированный указатель источников](sources.json)
- [Шаблон нагрузки](workload_example.json) и [калькулятор нижних оценок](calculator.py)

Исходный редакционный текст находится в `hardware_content.py`. PDF собирается командой `python3 build_pdf.py` после установки `pyphen` из `requirements.txt`; нужны XeLaTeX, русскоязычная поддержка polyglossia, Nimbus Sans и шрифты `assets/fonts` репозитория. Старый `typeset_book.py` воспроизводит только отклонённый короткий черновик и не является генератором этого PDF.

Запуск `python3 calculator.py workload_example.json` даёт нижние оценки трёх массивов, но не вывод о совместимости. Цены и выбор конкретных моделей комплектующих проверяются на дату покупки.

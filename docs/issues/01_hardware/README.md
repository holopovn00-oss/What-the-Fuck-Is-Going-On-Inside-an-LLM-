# Выпуск 01. Железо для ИИ: от задачи к конфигурации

Текущий кандидат — **редакция 1.2**. Восемь частей и 24 страницы по [Golden Gate](../../standards/atlas_golden_gate/GOLDEN_GATE.md). Один учебный проект связывает путь документов, память и очередь, обучение, RAG, локальный запуск и выбор конфигурации. Восьми местным библиографиям соответствуют 32 записи (27 разных источников). Структурная проверка прошла, редакционная самопроверка заполнена, **решение пользователя ожидается**.

Исходный редакционный текст находится в hardware_content_12.py, каталог литературы — source_catalog.py. PDF собирается командой python3 build_pdf.py после установки pyphen из requirements.txt; нужны XeLaTeX, русскоязычная поддержка polyglossia, Nimbus Sans и шрифты assets/fonts репозитория. hardware_content.py относится к отклонённой редакции 1.1; старый typeset_book.py воспроизводит лишь более ранний короткий черновик.

Запуск python3 calculator.py workload_example.json даёт нижние оценки трёх массивов, но не вывод о совместимости. Текущий выпуск не утверждает, что конкретный checkpoint запустится на конкретной карте. Цены, совместимость и выбор комплектующих сверяются на дату покупки.

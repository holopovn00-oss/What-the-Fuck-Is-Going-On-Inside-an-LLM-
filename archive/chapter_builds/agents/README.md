# Архитектура агентов: исходники

Читательский результат: `../atlas_agents_architecture.pdf`. 24 страницы; обзор и семь подтем, после каждой статьи местная библиография. Полный Atlas этим файлом не исчерпывается.

## Повторная сборка

В каталоге `source` дважды выполнить `xelatex -interaction=nonstopmode -halt-on-error typeset.tex`.
Нужны XeLaTeX/TeX Live, fontspec, polyglossia, unicode-math, amsmath, xcolor, eso-pic, fancyhdr, needspace, changepage, hyperref; Latin Modern Math и Nimbus Sans из URW Base35 по пути, указанному в преамбуле. Шрифты основного текста находятся в `fonts/`.

`chapter.tex` — читаемый LaTeX. `typeset.tex` — тот же материал с явными русскими переносами. `content.py` — тексты и источники. `build_workspace.py` сохраняет генератор этой сессии: для переноса самого генератора требуется изменить корень R и пути к шрифтам и pyphen. Для повторной сборки готового текста достаточно `typeset.tex`.

`sources.json` хранит полные имена авторов, адреса прочитанных редакций, русские аннотации, назначенные разделы и статус доступа. `verification.json` фиксирует проверки PDF. Научные эксперименты и программные системы цитируемых работ не воспроизводились; числа в тексте учебные. HTML и PDF сторонних работ в архив не включены.

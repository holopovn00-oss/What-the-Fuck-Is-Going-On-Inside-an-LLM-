# Атлас: решения, структура и исследовательские заметки

Дата: 2026-09-12. Версия пакета: 0.5.

## Состав

1. **01_decisions.md** — требования пользователя, утверждённая подача PDF, изменения решений и открытые статусы.
2. **02_atlas_structure.md** — все 65 прежних тем и подтем, распределённые по шести блокам, с дополнениями из 21 направления и текущего анализа.
3. **03_profiles_review.md** — пять аккаунтов, доступные авторские ресурсы, тематическая специализация и ограничения проверки.
4. **04_plan_changes.md** — 14 адресных изменений: четыре новые явные подтемы, девять углублений и одна методическая правка.
5. **05_sources_by_topic.md** — 22 адресные записи с русской аннотацией, местом чтения и статусом проверки; записи сгруппированы по темам.
6. **06_plugin_ideas.md** — идеи будущего плагина, не утверждённая спецификация и не реализация.
7. **07_atlas_registry.json** — структурированное представление карты, изменений и источников для последующего анализа.

## Как читать

Начать с журнала решений и изменений. Затем просмотреть нужные разделы карты и их адресные источники. Для будущего плагина использовать журнал и реестр вместе: JSON сам по себе не заменяет требования и редакционные решения.

## Степень готовности

Сохранены решения, доступные в текущем диалоге и рабочем плане. Это не полный архив всех чатов. Полный просмотр лент X заблокирован; анализ опирается на связанные первичные ресурсы. Все источники имеют честный статус доступа. В предыдущей итерации существующие PDF не изменялись. В продолжении создана отдельная глава Deep Research; её состав и пределы покрытия описаны в файле 09.

Итоговый читательский продукт по-прежнему PDF с библиографией внутри тем. Markdown и JSON здесь служат рабочими записями для обсуждения и будущей автоматизации.

# Книжное оформление библиографии по референсу

Статус: пользователь задал направление книжным референсом; конкретная адаптация представлена одностраничным образцом. Основная глава пока не перевёрстана.

Признаки: спокойное serif-начертание, фамилии с инициалами, год в скобках, оригинальные названия курсивом, выступ первой строки, центрированные заголовки, тонкая линия под названием и номер страницы по центру.

Сохранены номер записи, русский перевод названия, содержательная аннотация, указание разделов для чтения и кликабельные заголовки. Аннотации выравниваются с продолжением библиографической строки.

В образце те же PROV-O, ALCE и Argus, что в сравнении трёх вариантов. Новые научные утверждения не добавлялись.

Файл: bibliography_book_style.pdf. Это адаптация книжной манеры, а не заявление о точном воспроизведении шрифта издательства. Основной текст Source Serif 4.

## Уточнение пользователя

Из книжного образца удалена строка «Свидетельства, происхождение и цитаты» под заголовком «Библиография». Заголовок, тонкая линия, группы и аннотированные записи сохранены.

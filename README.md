# What the Fuck Is Going On Inside an LLM?

Атлас устройства и применения искусственного интеллекта.

Исследовательский и учебный проект о том, как устроены современные модели ИИ и системы вокруг них: от математических основ и архитектур до агентов, Deep Research, RAG, инженерии использования и аппаратной инфраструктуры.

**Текущая редакция содержания — 4.0 от 26 сентября 2026 года:** 7 блоков, 82 главы, 924 подтемы. Содержание — карта работы, а не 924 уже написанные главы. [Текущий план](docs/contents/atlas_contents.md) · [PDF](docs/contents/atlas_contents.pdf) · [машинная версия](docs/contents/atlas_contents.json).

## Как читать статус

В [STATUS.md](STATUS.md) разделены покрытие тем в плане и готовность учебных глав. Прочитанное и проверенное, описанное только по аннотации и исследовательские гипотезы не считаются равнозначными источниками. Имена Jev и JEPA относятся к разным направлениям; заявления о производительности молодых продуктов отмечаются отдельно от независимой проверки.

## Сборка содержания

Нужны Python 3 и XeLaTeX с пакетами, используемыми в `src/build_contents.py`. Шрифты Source Serif 4 лежат в `assets/fonts/` с отдельной лицензией. Команда из корня репозитория:

```bash
python3 src/build_contents.py
```

Результаты записываются в `build/output/`. JSON и Markdown из этой сборки побайтно совпадают с опубликованной редакцией; PDF содержит то же содержание, но технические метаданные и бинарный файл могут различаться при повторной компиляции. Источники ранних глав сохранены как архив разработки и пока не образуют переносимый конвейер сборки.

При изменении плана сохраняйте прежние идентификаторы тем, обновляйте генератор, реестр и журнал решений, затем сверяйте Markdown, PDF и машинную версию. Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).

Авторские материалы проекта пока не получили общей лицензии. Внешние работы приведены ссылками и аннотациями, а не копиями статей. Шрифты имеют собственную лицензию OFL в `assets/fonts/LICENSE.md`.

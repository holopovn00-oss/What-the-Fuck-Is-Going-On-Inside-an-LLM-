# Шрифты сборки

В этой папке лежат Source Serif 4 Regular, Bold и Italic от Adobe. Они используются при сборке PDF содержания. Шрифты распространяются по SIL Open Font License 1.1; полный текст и уведомление об авторских правах — в [LICENSE.md](LICENSE.md). Исходный проект: https://github.com/adobe-fonts/source-serif.

Лицензия шрифтов не определяет права на остальные материалы Атласа.
